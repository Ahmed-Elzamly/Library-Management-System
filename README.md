# Library-Management-System
## 📖 Overview
The **Library Management System** is a Java-based application designed to manage books, users, and transactions efficiently. It provides a user-friendly graphical interface (GUI) and integrates with a MySQL database for secure data storage.

## 🔧 Features
- 📌 **User Management:** Add, edit, and remove users (students, librarians, etc.)  
- 📌 **Book Management:** Add, update, delete, and search for books  
- 📌 **Borrowing & Returning:** Track book loans and returns  
- 📌 **Database Integration:** Uses MySQL for persistent storage  
- 📌 **GUI Interface:** Built with Java Swing for ease of use
